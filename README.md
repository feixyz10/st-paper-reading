# st-paper-reading

带着原图、公式和具体例子阅读单篇论文，讲清方法为什么存在、输入如何变成输出、训练如何得到这种能力，以及实验支持哪些结论。默认精读，明确要求时可泛读；也支持按需讨论基于论文的后续研究。尤其适合机器人、VLA、世界模型与深度学习论文，也可按论文类型调整讲解路线。

完整的阅读指引见 [SKILL.md](SKILL.md)。文档采用通用表述，工具与展示方式由使用环境决定。

## 使用方式

将本目录放入使用环境的技能目录，按该环境的方式加载 `SKILL.md`；也可以直接提供该文件作为阅读指引。具体加载位置与自动发现方式以使用环境为准。

提供论文 HTML/PDF 链接、本地 PDF 或已有材料，再说明想读的范围，例如：

```text
带我精读这篇论文：<论文链接>
泛读这篇论文，控制在十分钟左右：<论文链接>
直接讲架构，对着方法总览图说明模块的输入输出。
讲清损失函数，用一组小数字算一遍。
一条训练样本到底长什么样？
拿一个具体例子，对照官方代码走一遍推理。
一次讲完，并把笔记保存到 papers/<论文目录>/。
基于这篇论文提出后续研究方向，说明依据、可检验假设和最小验证实验。
```

精读默认从动机开始，每次围绕一个问题讲解，讲完询问是否继续。可以随时插话、跳到某一站，或要求一次讲完。泛读默认一次交付整篇导读。批量文献检索、仅一句话总结和审稿不属于本技能的范围。

## 精读与泛读

| | 精读（默认） | 泛读（明确要求时启用） |
|---|---|---|
| 目的 | 理解方法机制与关键细节 | 能讲清要解决的问题和具体解决办法，并了解证据与边界 |
| 时间目标 | 完整互动通常需半小时以上，按需要深入 | 约 10 分钟，控制准备范围与讲解体量 |
| 讲解方式 | 六站渐进，也可按要求一次讲完 | 默认一次给出紧凑导读，不逐站确认 |
| 方法、训练与数据 | 展开模块接口、损失、样本和信息流 | 讲清模块职责、连接关系或算法步骤，串起输入到输出，保留训练目标、数据来源与推理方式 |
| 公式、例子与代码 | 解释关键公式，用具体样本或示意例子走查，必要时对照代码 | 通常省去详细推导、逐维样本和代码追踪，只留必要公式或简短示意 |
| 证据要求 | 核验原图、公式、关键数字与主张边界 | 同样核验，优先决定性证据；明确未读、未核实范围 |

“读一下”仍默认精读。只有明确要求泛读、快速浏览整篇或十分钟导读时才切换；简短的局部提问不会改变整篇模式。时间是内容范围的目标，不是固定耗时承诺，材料获取困难和后续追问会影响实际时长。

同篇论文的后续沿用已明确的模式；换论文时按当前要求选择，未指定则默认精读，除非已有适用于后续论文的明确偏好。切换时复用身份与版本匹配、已经核实的材料。

## 精读：六站阅读路线

| 站 | 要讲清的问题 |
|---|---|
| ① 动机 | 任务是什么，已有方法卡在哪里，作者改变了什么？ |
| ② 架构 | 图中的模块各做什么，输入输出如何连接？ |
| ③ 训练 | 预测什么，监督从哪里来，损失如何推动学习？ |
| ④ 数据 | 一条样本有哪些字段、形状、单位，如何变成模型输入？ |
| ⑤ 信息流 | 从输入到输出经过哪些步骤，哪些计算循环执行？ |
| ⑥ 具体例子 | 用具体数值或形状，把整个机制走一遍。 |

关键实验与局限在适当时机补充。两种模式均按论文类型调整：非学习方法不强套训练，理论论文讲假设、结论与证明思路，以决定性论证替代实验。

## 泛读：约十分钟保留什么

读完应能复述两个核心问题：**论文要解决什么问题？具体怎么解决？** 模型方法讲清主要模块及其连接，算法方法讲清步骤和必要的状态变化，并说明关键改变如何解决原有瓶颈。讲解应串起“输入 → 主要模块或步骤 → 关键中间结果 → 输出”，不止列出术语和贡献。

| 环节 | 参考时间 | 核心内容 |
|---|---|---|
| 问题与贡献 | 1 分钟 | 论文身份、输入输出、已有瓶颈与关键改变 |
| 具体方法 | 4 分钟 | 对照原图讲清架构连接或算法步骤，串起输入到输出，交代训练目标、数据来源与推理方式 |
| 关键证据 | 2 分钟 | 决定性结果、比较条件及其支持的结论 |
| 边界与直觉 | 2 分钟 | 主要局限、未知点与简短场景示意 |
| 阅读判断 | 1 分钟 | 适用问题，以及值得进一步精读的章节、图或公式 |

泛读不只是复述摘要。先读摘要、引言中的问题与贡献、方法核心段落、关键结果及局限，附录只查会改变判断的细节；仍查看并展示讲解依赖的原图，核对核心实验与结论，没有总览图时可用标注为示意的简图。通常不做完整损失手算、逐层形状追踪、多轮例子或代码调用链走查。中文正文通常约 1500–2500 字，随图表复杂度和背景调整。时间不足时先压缩背景、次要结果、扩展讨论和阅读建议，保留问题、具体方法、决定性证据与关键边界。

只取得摘要、未能核实核心方法或未取得决定性证据时，标为受限概览，不称为已完成整篇泛读；末尾说明最影响判断的未读或未核实部分。

## 研究延伸：按需启用

明确询问后续研究方向、项目迁移或下一步实验时启用，精读与泛读都不默认附加。也可单独请求，无需先讲完整篇；复用已有阅读成果，按需补核支撑建议的证据。已有项目背景和资源约束就沿用，未知条件标为假设。在此基础上提出少量建议：

- **依据与缺口**：论文证明了什么，哪些问题仍未解决，原文证据在哪里。
- **假设与条件**：提出可检验假设，说明可迁移之处及可能失效的前提。
- **最小验证**：给出方法、数据、基线与对照，以及支持或否定假设的可观察结果。
- **优先级**：结合信息价值、成本和已知资源，确定先做什么、得到什么交付物。

区分作者建议与自己的提案，分别判断研究线索、实验可行性与新颖性；未经相关工作核查，不声称方向具有创新性。证据不足时先提出获取证据的步骤；研究计划不代表已经完成实验或授权执行。

泛读中同时请求研究启发时，通常保留一至两个方向及首个验证动作，计入约 10 分钟，保留问题、具体方法、决定性证据与关键边界。详细研究方案按明确请求展开并说明超出该预算；若仍坚持十分钟上限，先给出预算内的方向与首个验证动作，详细方案留待后续。

## 材料与工具

优先使用已有材料，有可读全文就开始。HTML、电子版 PDF 和扫描版 PDF 按各自特点读取；公式、图表有歧义时再补充同版本材料。只有摘要或片段时，只解释能核实的内容。

本技能不附带脚本，也不要求固定解析库、预先下载 LaTeX 源码或克隆代码。使用环境需提供与当前任务相应的能力：读取材料，查看和展示图片，以及在需要时访问链接、保存文件或查询官方实现。能力不足时说明影响范围。

需要保存材料时，每篇论文使用独立目录，沿用指定位置；未指定时可使用 `papers/<论文ID及版本>-<短标题>/`。按需保存原文、已使用的图片、代码和笔记，不提前生成完整材料包，不把阅读产物写进技能目录。

## 讲解与证据

- 先查看图像，再解释图；讲解依赖某张图时展示原图或清晰裁剪。
- 裁剪保留必要子图、坐标轴、单位、图例和脚注；只讲部分子图时说明范围。
- 关键设计说明所解决的问题、选择理由及可行替代方案，区分作者解释与自己的推断。
- 核验关键公式、数字和表格，给出章节、页码、图号或公式号等出处。
- 区分原文公式、等价改写和额外推导，说明成立假设；数值检查不能替代一般证明。
- 将核心主张对应到具体证据，说明支持、限制或反驳它的结果及实验条件。
- 区分论文报告、代码实现、解释推导与示意假设；未知信息保留为未知。
- 只在需要时查官方代码，核对版本与配置；默认只读，不安装训练环境或运行仓库程序。
- 用户要求保存或项目已有持续笔记约定时才写笔记，并区分已准备内容与已交付讲解。
